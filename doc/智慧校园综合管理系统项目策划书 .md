# 智慧校园综合管理系统 项目策划书

**项目名称：**智慧校园综合管理系统（含在线考试、AI学情分析）

**技术架构：**前后端分离架构

**前端框架：**Vue3 \+ Element Plus（PC端教师/学校后台）\+ Vant（学生端移动端适配）\+ Vite 构建

**后端框架：**SpringBoot 3 \+ MyBatis\-Plus \+ MySQL 8\.0 \+ Redis

**AI 模块：**对接火山方舟（Ark）大模型，使用模型 **Doubao\-Seed\-2\.1\-pro**；承担 AI 题目生成、AI 成绩学情分析、教师端学生画像实时诊断三类能力

**通信方式：**Axios 请求，JWT 登录鉴权

**代码规范：**页面组件、JS 逻辑、CSS 样式文件分离；每个功能页面独立文件；业务数据全部持久化至 MySQL

# 项目概述

本智慧校园系统面向**初级中学（初中）**，覆盖初中 9 个中考科目：**语文、数学、英语、道德与法治、历史、地理、物理、化学、生物**。系统实现**学生、任课教师、班主任、学校管理员**多角色权限隔离。核心包含在线考试模块、校本题库、AI 智能出题、AI 学情分数分析、课表管理、学生档案、评奖评优、班级人员管理、任课教师调配审批。

所有考试试卷、试题、成绩、课表、用户档案、任职信息全部存储在 MySQL 数据库。系统分为三大客户端：**学生端、教师端、学校管理后台**，基于前后端分离开发，前端使用 Vue3 框架，后端 SpringBoot，每个功能页面 HTML、JS、CSS 独立拆分文件，方便维护。

## 核心特色

1. 在线考试：学生在线答题，试卷存储 MySQL，支持 AI 实时生成试卷；

2. AI 学情分析：考完自动对学生成绩进行 AI 分析，输出薄弱知识点、成绩趋势、学习建议；

3. 权限精细化区分：任课教师 / 班主任权限隔离；任课仅看本科成绩，班主任看全班全部科目、可编辑学生评奖评优档案；

4. 审批流：教师选拔课代表需班主任审批；班主任提交任课教师更换申请由学校后台审核；

5. 任职管理：学生任职（班委）、教师任职、班主任配置统一管理，列表展示任职信息；

6. 课表自动管理，学生、教师登录自动展示个人课表；

7. 校本题库私有化：每所学校登录后台后仅能查看和管理本校题库，校与校之间数据隔离；教师可手动录题，也可调用 AI 批量生成题目（生成数量可选），预览后勾选需要的题目入库；组卷考试时同样支持 AI 按科目/知识点批量生成、教师再挑选题目入卷。

# 项目目标

1. 数字化线上考试，试题、试卷、成绩全部存入 MySQL，支持师生实时查看试题；

2. 精细化权限管控，区分学生、任课教师、班主任、学校管理员权限；

3. AI 赋能：AI 自动组卷、AI 学生成绩多维学情分析；

1. 校本题库私有化：每所学校独立维护本校 9 科题库，校际数据隔离；支持手动录题与 AI 批量出题（数量可自定义），教师预览后勾选入库；

2. 班级人事管理：课代表选举审批、任课教师更换申请审批、学生班委任职管理；

3. 学生档案管理，支持评奖评优记录；

4. 统一课表管理，学生、教师登录自动展示个人课表；

5. 代码工程化，前端页面功能拆分独立文件，结构清晰，方便迭代扩展。

# 系统整体架构设计

采用主流前后端分离架构，分层职责如下：

```text
【前端层】Vue3 + Element Plus + Vite
    ├─ 学生端页面（独立页面组件，html/css/js 分离）
    ├─ 教师端页面（独立页面组件，html/css/js 分离）
    └─ 学校后台页面（独立页面组件，html/css/js 分离）
        ↓ Axios + JWT Token
【后端服务层】SpringBoot 3 + MyBatis-Plus
    ├─ 登录鉴权模块(JWT)
    ├─ 用户 & 权限模块
    ├─ 课表模块
    ├─ 题库 & 试卷模块
    ├─ 在线考试模块
    ├─ 成绩 & AI 学情分析模块
    ├─ 班级、任职、审批流模块
    ├─ 学生档案、评奖评优模块
    ├─ AI 接口服务模块（调用大模型 API）
    └─ 文件上传模块
        ↓
【数据持久层】MySQL 8.0（主业务库） + Redis（缓存登录 token、热点题库、考试临时数据）
```

## 架构说明

1. JWT 无状态登录：登录成功返回 token，每次请求携带 token，后端校验身份与角色；

2. Redis：缓存登录状态、考试倒计时、高频查询的题库与课表信息，减轻 MySQL 压力；

3. AI 模块独立接口：后端封装 AI 请求，前端接收 AI 返回分析文本；AI 生成题目后自动格式化入库到 MySQL 试题表；

4. 所有业务数据（用户、班级、试题、试卷、考试记录、答题记录、成绩、档案、审批记录）全部持久化 MySQL；

5. 前端每个功能页面拆分为单独 Vue 组件（模板 html、独立 css 样式、独立 js 逻辑）。

# 角色划分与权限总览

**后台账号层级（自上而下）**

**① 超级管理员（平台主账号）**：系统初始化时预置的唯一最高账号，**不开放注册**。可查看并管理**全部学校**信息、创建 / 停用学校、审核学校普通管理员的账号申请；拥有平台全部数据可见权。

**② 学校普通管理员（每校最高管理员）**：由超级管理员在创建学校时直接分配，或由已有校管理员发起申请、经超级管理员审批通过后开通。**只能看到自己所属学校的所有数据**，看不到其他学校；可在本校范围内创建普通后台账号（教务、年级组长等）。

**③ 学校普通后台账号**：由学校普通管理员创建，**仅归属本校**，按分配的菜单权限使用后台；同样看不到其他学校。

**关键约束**：后台账号一律不能自行注册；普通管理员想新增后台账号时，需提交申请并经超级管理员审批通过后才生效。

## 学生角色

查看个人课表、参加在线考试、查看历史试卷、查看历次考试成绩、查看 AI 分数学情分析；查看个人班级与学生任职；查看通知中心收到的通知（只读）。**普通学生不能发布通知；班委可向本班或本班同学发布通知**。仅查看权限，不可修改任何考试与档案。

## 任课教师角色

查看个人任教班级与科目；选拔课代表（提交班主任审批）；从本校题库挑题组卷发布考试 / 调用 AI 批量出题后挑选入卷；查看本科目考试成绩；查看本班学生列表；**只能查看学生档案，不能编辑评奖评优**；**可发布通知，范围仅限自己任课的班级或这些班级里的具体学生**。

## 班主任角色（教师附加权限）

拥有任课教师全部权限；审批本班课代表申请；查看班级**全部科目考试成绩**；维护本班学生档案，新增 / 编辑评奖评优记录；提交任课教师更换申请；查看全班学生列表与学生任职。

## 学校普通管理员（校管理员，本校最高权限）

管理学校信息；更换班主任、调整教师任职；查看全校所有学生列表，列表显示学生任职信息；审核班主任提交的任课教师更换申请；管理全部用户账号；管理全校班级；管理本校私有题库；查看全校考试数据与全局统计；系统基础参数配置；**可发布通知，范围支持全校、指定多个班级、指定个人三种粒度**。

## 超级管理员（平台主账号，唯一）

系统初始化时预置的最高账号，**不开放任何注册入口**，登录后可见并管理**全部学校**的数据。核心能力：① 创建新学校、分配该学校的首个学校普通管理员账号；② 审批学校普通管理员提交的"新增后台账号"申请，通过后账号才生效；③ 跨校查看学生、教师、考试、成绩等全局数据（这是唯一能跨校看数据的角色）；④ 配置平台级参数（AI 接口密钥、学校套餐、全局公告）；⑤ 停用违规学校或账号。

# 各端详细功能需求

## 学生端

登录成功首页展示**所在班级、个人任职（班委）**，快捷入口：课表、我的考试、历史试卷、我的成绩、AI 学情分析、个人信息。每个功能独立页面文件（Login\.vue / Dashboard\.vue / Timetable\.vue / ExamList\.vue / ExamDo\.vue / HistoryPaper\.vue / ScoreList\.vue / AiAnalysis\.vue）。

1. **个人课表页面**：读取 timetable 表，按星期、节次展示科目、教师、教室；支持周切换。

2. **在线考试列表**：展示教师已发布、可参加的考试；显示试卷名称、科目、考试时长、截止时间；点击进入考试。

3. **在线考试答题页面**：读取试卷关联试题 paper\_question，实时加载题目；前端计时；自动保存答题草稿（定时提交到 MySQL 答题表）；提交试卷后自动批改客观题并计算总分；提交后自动调用 AI 接口生成本次考试学情分析，存入 ai\_score\_analysis 表。**顶部状态栏常驻显示倒计时、当前题号、切屏次数 X/3、教师解封次数**；前端监听 visibilitychange / blur 事件，每次切出考试窗口弹出居中警告弹窗"已记录第 X 次切屏，累计 3 次将强制交卷"，点"我知道了"才能回到答题；达到 3 次立即自动交卷并锁定入口，等待教师在考试管理页解封。

4. **历史试卷查看页面**：查看已考完的试卷原题（读取 MySQL 试题），查看题目、参考答案与解析。

5. **我的历次成绩页面**：列出所有参加考试记录，试卷名称、科目、分数、考试时间；点击单条成绩查看详情。

6. **AI 成绩学情分析页面**：读取 ai\_score\_analysis 表，展示 AI 分析内容（本次得分在班级排名、薄弱知识点、错题汇总、学习建议）；用 ECharts 图表可视化成绩趋势。

7. **个人信息页面**：查看个人信息、学号、任职；修改登录密码。

8. **我的通知中心页面**：卡片式消息列表，按时间倒序展示所有发给本人的通知（学校公告、考试通知、审批结果等）；未读通知带红点和浅蓝背景，已读置灰；点击进入详情后自动标记已读；顶部铃铛显示未读数；支持按通知类型筛选。**普通学生只读不能发**。

9. **班委专属：发布通知页面**：仅班委（班长/课代表等）可见。选择接收范围时只能勾选自己班级或本班内的具体同学；填写标题、正文、可选附件后提交，写入 message 表（publisher\_role=1 学生，target\_scope 仅限 2 班级 / 3 个人）。

## 教师端

登录首页展示**任教班级、任课科目**，区分普通任课教师 / 班主任标识。每个功能独立页面文件。

1. **班级学生查看页面**：查看对应班级全部学生列表，显示学生姓名、学号、任职信息。

2. **课代表管理页面**：教师选择本班学生提交课代表申请，写入 class\_rep 表，状态为待班主任审批；查看自己提交的课代表审批记录。

3. **班主任专属：课代表审批页面**：班主任查看本班课代表申请，同意 / 驳回，修改 class\_rep 的 audit\_status。

4. **校本题库管理页面**：仅展示本校题库（按 school\_id 隔离，看不到其他学校题目）。支持两种录题方式——① 手动新增：在线表单录入题干、选项、答案、解析、难度、知识点，存入 question\_bank；② AI 批量生成：教师选择科目（9 科之一）、年级、知识点范围、题型配比，**一次性指定生成题目数量（如 10/20/50 道，可自定义）**，AI 批量出题后以列表预览展示，教师**勾选满意的题目点"采纳入库"，不满意的丢弃**；被采纳的题目 review\_status 置为 1 并正式进入本校题库，未采纳的保留在批次中可随时再看。

5. **试卷创建 \& 发布考试页面**：支持两种组卷模式——① 从本校题库手动挑题：按科目、知识点、难度筛选，勾选题目并设置每题分值；② AI 实时出题：教师选择科目、年级、知识点、题型与每题分值，**指定一次性生成多少道候选题（可自定义数量）**，AI 批量生成后预览展示，教师**勾选需要的题目加入试卷**，未选中的题目可选择"一并收入题库"或丢弃。两种模式生成的题目都会先写入 question\_bank（带 ai\_batch\_no 批次），试卷与试题通过 paper\_question 关联。设置考试时间、允许参加班级、总分、时长后发布到学生端。

6. **考试管理页面**：查看自己创建的所有考试，查看试卷详情与所有试题；可以结束考试。**考试进行中实时看板**：展示本班学生在线状态、已交卷名单，以及"异常学生"标签——列出因切屏超限被强制交卷的学生，每个学生旁显示切屏次数（X/3）与已被解封次数；教师可对异常学生点"重新开放考试"，一键恢复答题入口并将切屏计数清零，操作即时生效并通过站内消息通知学生。**切屏次数、解封次数在教师看板和学生考试页顶部均可见**。

7. **成绩查看页面**：普通任课教师仅能查看自己所教学科本次考试分数；班主任查看班级本次考试全部科目成绩；支持导出 Excel 成绩。成绩列表中学生姓名做**蓝色可点击链接样式**，点击后右侧**平滑滑出抽屉（Drawer）**展示该学生的学情画像：① 顶部学生卡片（头像、姓名、学号、班级、本次分数与班级排名）；② 「最近考试成绩」折线图，按时间横轴展示该生历次考试分数趋势（任课教师仅显示本科目，班主任显示全科），同时叠加班级平均分参考线；③ 错题与薄弱知识点标签云；④ 底部「AI 实时分析」按钮——点击后流式输出该生近期学情诊断（波动原因、薄弱知识点、针对性学习建议），分析结果同时存入 `ai_score_analysis` 表便于下次直接查看，无需重复调用。抽屉支持手势/点击遮罩关闭，操作动效流畅。

8. **学生档案查看页面（所有教师只读）**：查看学生基础档案、历史评奖评优记录；教师只有查看权限，不能新增 / 修改。

9. **班主任专属：评奖评优管理页面**：班主任编辑本班学生档案，新增、修改、删除学生评奖评优记录，写入 student\_award。

10. **班主任专属：任课教师更换申请页面**：班主任填写申请（班级、科目、原老师、新老师、申请理由），提交至学校后台等待审核，写入 teacher\_change\_apply 表，查看审批进度。

11. **个人信息页面**：修改密码。

12. **通知中心页面**：所有教师（含班主任）共用。卡片式消息列表展示发给本人的通知，未读红点提醒；发布考试、课代表审批结果、任课更换申请结果等系统消息自动入此列表；支持按类型筛选。

# 非功能性需求

1. **性能**：在线考试支持多人同时在线答题，Redis 缓存，防止 MySQL 高并发压力；

2. **安全**：密码 BCrypt 加密存储；JWT 鉴权；接口权限拦截，不同角色禁止访问不属于自己的接口；防考试切屏（前端监测）；SQL 防注入；XSS 防护；

3. **兼容性**：Chrome、Edge 主流浏览器；

4. **可扩展性**：模块解耦，后续可增加考勤、宿舍、请假模块；

5. **数据备份**：MySQL 定时备份脚本。
