# 智慧校园综合管理系统

面向**初级中学（初中）** 的智慧校园综合管理系统，覆盖初中 9 个中考科目，集在线考试、AI 学情分析、校本题库、课表管理、班级人事、评奖评优于一体，实现**学生、任课教师、班主任、学校管理员**多角色权限隔离。

## 项目概述

系统覆盖初中 9 个中考科目：**语文、数学、英语、道德与法治、历史、地理、物理、化学、生物**。核心包含在线考试、校本题库、AI 智能出题、AI 学情分数分析、课表管理、学生档案、评奖评优、班级人员管理、任课教师调配审批等模块。

所有考试试卷、试题、成绩、课表、用户档案、任职信息全部持久化存储于 MySQL。系统分为三大客户端：**学生端、教师端、学校管理后台**，基于前后端分离架构开发。

## 技术架构

| 层次 | 技术栈 |
| --- | --- |
| 前端框架 | Vue3 + Element Plus（PC 端）+ Vant（学生端移动适配）+ Vite |
| 后端框架 | SpringBoot 3 + MyBatis-Plus |
| 数据库 | MySQL 8.0（主业务库）+ Redis（缓存） |
| AI 模块 | 火山方舟（Ark）大模型 `Doubao-Seed-2.1-pro` |
| 通信方式 | Axios 请求 + JWT 登录鉴权 |

系统分层职责如下：

```text
【前端层】Vue3 + Element Plus + Vite
    ├─ 学生端页面（独立页面组件，html/css/js 分离）
    ├─ 教师端页面（独立页面组件，html/css/js 分离）
    └─ 学校后台页面（独立页面组件，html/css/js 分离）
        ↓ Axios + JWT Token
【后端服务层】SpringBoot 3 + MyBatis-Plus
    ├─ 登录鉴权模块(JWT)
    ├─ 用户 & 权限模块
    ├─ 课表模块
    ├─ 题库 & 试卷模块
    ├─ 在线考试模块
    ├─ 成绩 & AI 学情分析模块
    ├─ 班级、任职、审批流模块
    ├─ 学生档案、评奖评优模块
    ├─ AI 接口服务模块（调用大模型 API）
    └─ 文件上传模块
        ↓
【数据持久层】MySQL 8.0（主业务库） + Redis（缓存登录 token、热点题库、考试临时数据）
```

## 核心特色

1. **在线考试**：学生在线答题，试卷存储 MySQL，支持 AI 实时生成试卷；
2. **AI 学情分析**：考后自动对学生成绩进行 AI 分析，输出薄弱知识点、成绩趋势、学习建议；
3. **权限精细化区分**：任课教师 / 班主任权限隔离，任课仅看本科成绩，班主任看全班全部科目；
4. **审批流**：教师选拔课代表需班主任审批，班主任提交任课教师更换申请由学校后台审核；
5. **任职管理**：学生任职（班委）、教师任职、班主任配置统一管理；
6. **课表自动管理**：学生、教师登录自动展示个人课表；
7. **校本题库私有化**：每所学校仅能查看和管理本校题库，校际数据隔离；支持手动录题与 AI 批量生成题目。

## 角色与权限

| 角色 | 核心权限 |
| --- | --- |
| 学生 | 查看个人课表、参加在线考试、查看历史试卷与成绩、查看 AI 学情分析、查看通知 |
| 任课教师 | 选拔课代表、组卷发布考试、查看本科目成绩、查看学生列表、查看学生档案（只读） |
| 班主任 | 任课教师全部权限 + 审批课代表、查看全部科目成绩、维护学生档案与评奖评优、提交任课更换申请 |
| 学校普通管理员 | 管理本校全部数据：学校信息、用户账号、班级、教师任职、题库、考试统计、系统参数 |
| 超级管理员 | 唯一平台主账号，跨校查看与管理全部学校数据，审批后台账号申请 |

后台账号层级：**超级管理员 → 学校普通管理员 → 学校普通后台账号**，后台账号一律不能自行注册。

## 功能模块

### 学生端

- 个人课表、在线考试列表、在线答题（含切屏防作弊检测）
- 历史试卷查看、历次成绩查看、AI 成绩学情分析（ECharts 可视化）
- 个人信息、通知中心（普通学生只读，班委可向本班发布通知）

### 教师端

- 班级学生查看、课代表管理 / 审批（班主任专属）
- 校本题库管理（手动录题 + AI 批量出题）、试卷创建与发布（手动挑题 + AI 实时出题）
- 考试管理（实时看板、异常学生解封）、成绩查看（学生学情画像抽屉 + AI 实时分析）
- 学生档案查看（只读）、评奖评优管理（班主任专属）、任课教师更换申请（班主任专属）
- 通知中心与发布通知（仅限自己任课班级）

### 学校后台管理端

- 学校基础信息、用户账号、班级、教师任职、全部学生列表
- 任课教师更换申请审批、本校题库总管理、全局考试统计
- 系统参数配置、日志管理、通知发布与管理
- 校管理员专属：申请新增后台账号
- 超级管理员专属：学校管理、后台账号申请审批、跨校数据总览

### 核心扩展功能

- **消息通知模块**：所有通知统一入库，按角色分级发布，卡片式通知中心 + 未读红点 + 铃铛推送
- **密码找回**：密保问题 + 双好友验证，6 位随机临时密码，30 分钟有效
- **操作日志审计**：AOP 切面自动记录所有写操作与关键读操作，只追加不修改
- **考试防作弊**：切屏检测（默认 3 次强制交卷）、教师可解封重新开放考试
- **数据导出 Excel**：成绩、学生档案、教师名册、题库、通知已读统计、操作日志等
- **全局数据看板**：ECharts 可视化大屏，成绩分析、质量分析、运营区，支持点击下钻

## 数据库设计

核心数据表（均设置逻辑删除字段 `deleted`，支持软删除）：

- 用户与权限：`user`、`security_question`、`friend_guardian`、`admin_account_apply`
- 学校与班级：`school`、`class`
- 学生与任职：`student`、`student_award`、`teacher_job`、`class_rep`
- 课表与题库：`timetable`、`question_bank`
- 考试相关：`exam_paper`、`paper_question`、`exam_record`、`exam_answer`、`ai_score_analysis`
- 审批与通知：`teacher_change_apply`、`message`、`message_receiver`
- 审计：`operation_log`

> 详细字段说明见 [项目策划书](doc/智慧校园综合管理系统项目策划书 .md)。

## 快速开始

### 环境要求

- JDK 17+
- Node.js 18+
- MySQL 8.0
- Redis

### 后端启动

1. 创建数据库并导入初始化 SQL；
2. 修改 `backend/src/main/resources/application.yml` 中的数据库、Redis 及 AI（Ark）配置；
3. 打包并运行：

```bash
mvn clean package
java -jar target/smart-campus-platform.jar
```

### 前端启动

```bash
# 以学生端为例，教师端、后台端同理
cd frontend/student-web
npm install
npm run dev
```

## 部署方案

1. **数据库**：MySQL 8.0 独立部署，Redis 独立；
2. **后端**：SpringBoot 打包 Jar，服务器运行；
3. **前端**：打包 dist，Nginx 部署学生端、教师端、后台三个站点；
4. **Nginx**：反向代理后端接口；
5. **AI 能力**：后端通过 HTTPS 调用火山方舟（Ark）OpenAPI，接入模型 `Doubao-Seed-2.1-pro`，相关配置位于 `application.yml`。

## 非功能性需求

- **性能**：多人同时在线答题，Redis 缓存降低 MySQL 高并发压力；
- **安全**：密码 BCrypt 加密、JWT 鉴权、接口权限拦截、防考试切屏、SQL 防注入、XSS 防护；
- **兼容性**：Chrome、Edge 主流浏览器；
- **可扩展性**：模块解耦，后续可增加考勤、宿舍、请假模块；
- **数据备份**：MySQL 定时备份脚本。
